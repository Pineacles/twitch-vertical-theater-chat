# Privacy Policy — Twitch Vertical Theater Chat

Effective: 2026-07-12

**This extension collects no data. Period.**

- It has no analytics, no telemetry, no tracking, and no error reporting.
- It makes no network requests of its own. It only rearranges elements that
  Twitch has already loaded in your browser.
- It never reads, stores, or transmits anything about the streams you watch,
  the messages you write, or your Twitch account.
- Your four preferences (on/off, chat position, chat visibility, and the
  narrow-window threshold) are stored with `chrome.storage.sync`, which lives
  in your own browser profile and — if you use browser sync — your own
  Google/Brave sync account. The developer has no access to it.
- It runs only on `twitch.tv` pages and requests no host permissions beyond
  that.

If any of the above ever changes, the change will be visible in this file's
git history and in the extension's changelog before a release ships.

Questions: open an issue at
<https://github.com/Pineacles/twitch-vertical-theater-chat/issues>.
